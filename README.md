The Cosmos — Staging Site
This repository contains the staging site for "The Cosmos" — a small fan portal for music, books, lore, and community.

Live demo: https://thecosmosofwacky.netlify.app
Built with: plain HTML, CSS, and JavaScript
Features: a simple To‑Do manager (stored in browser localStorage) and a small site scaffold for pages
Quick notes

Edit files locally and push to GitHub; Netlify will auto-deploy on commits.
To add pages, create new .html files at the repo root and link them from index.html.
How to commit this change (GitHub web UI)

Paste the README.md content above into the editor (replace the commands that are there now).
Click the Preview tab to check formatting.
At the bottom, in "Commit changes" fill the Title with: Add README
(optional) add a short description below it.
Select "Commit directly to the main branch" and click Commit changes.
